# Decision Guard

`git commit` in a product repo is blocked while the commit adds, removes or renames tests or
changes their asserts or numbers; the hook prints the triage command and the classes.
- Classify honestly: `policy` whenever expected behavior changes, even at her own request;
  `bugfix` only moves code toward behavior already agreed; deleting or thinning tests is `prune`
- `policy` needs a decision card and her reply before the commit; a subagent stops and sends the
  card to its parent
- List every triaged test in the final reply (test, change, class, why); show the card for `policy`
- If a requirement contradicts behavior pinned by tests or an earlier decision, show the card
  before implementing
