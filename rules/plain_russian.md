# Plain Russian for Drafts and Responses

When drafting replies for GitHub, Buganizer, Gerrit, or answering the user in Russian:
- Write in simple, clear, human-readable Russian.
- Strip out cryptic English abbreviations, C++ noise, and deep code identifiers (e.g. `SkScalarFloorToScalar`, `MRE`, `Win32 DIB`, `JIS`, `A8`, `Typography.blackRedmond`) unless they are the direct subject of a code snippet or absolutely necessary for the reader.
- Keep the drafts short and direct. Prioritize the high-level explanation over low-level execution details in the prose.
- Do not blindly translate technical jargon if it makes the text unreadable; explain the concept simply.
